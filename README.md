# G5 TV

G5 TV is a compact start page for an iDrive 7 browser. It links to official streaming sites and routes searches to YouTube, Netflix, Crunchyroll, or web search. It does not host streams, handle subscriptions, or bypass provider playback restrictions.

The mark is an original G5 TV design using three motorsport-inspired colors; it is not an official BMW or BMW M logo.

## Use with iDrive 7

Install the community MGU Browser from its MGU Store source, then set the browser's homepage to the published G5 TV page. G5 TV is a browser start page, not a native MGU Store package. Provider video playback depends on the browser's engine, codecs, DRM support, and each service's current rules.
